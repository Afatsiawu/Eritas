# **App Name**: TransitPro

## Core Features:

- Driver Sign-Up & Authentication: Secure onboarding process with enrollment code verification, auto-fetch of driver details, and biometric login with offline fallback.
- Home Dashboard: Displays current route, trip status, passenger count, estimated next stop, and live earnings summary with large, easy-to-tap UI elements.
- Live Trip Screen: Real-time map showing bus location, upcoming stops, and passenger boarding requests. Traffic-aware route suggestions using an AI tool.
- Boarding & Verification: QR code scanner for passenger boarding with visual confirmation of passenger details and seat reservation. Includes a manual override for network issues.
- Music Control (Spotify Integration): Displays current song, passenger-voted playlist, and driver controls (play/pause/skip) with volume indicator. Option to disable music.
- Notifications & Alerts: Smart alerts for overspeed, route deviation, low wallet balance, and emergency situations. Non-distracting UI with sound cues.
- Earnings & Performance: Daily trip summary, passengers served, earnings breakdown, driver rating score, and weekly performance trends.
- Support & Safety: Emergency button connecting to a control center, in-app support chat, incident reporting with photo upload, and safety checklist reminders.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) for a professional and reliable feel, reminiscent of transportation brands.
- Background color: Very light lavender (#F0F2FA) to create a clean and modern look that reduces eye strain during long shifts.
- Accent color: Vibrant amber (#FFB300) for key CTAs and alerts, providing a clear visual hierarchy.
- Body and headline font: 'PT Sans' for clear readability and a modern feel, appropriate for on-the-go usage.
- Use simplified, high-contrast icons to quickly convey information and reduce cognitive load.
- Prioritize a clear and intuitive layout with large, high-contrast buttons for easy interaction while driving.
- Subtle animations for transitions and feedback to improve user experience without causing distractions.
